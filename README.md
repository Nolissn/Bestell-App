# Burger House

A small food ordering website — a vanilla JavaScript project built for learning purposes.

---

## About

Burger House lets you browse a menu of burgers, pizzas and salads, add dishes to a basket and place an order. The basket updates live, calculates subtotal, delivery fee and total, and confirms the order in a dialog. Built without any framework or library — plain HTML, CSS and JavaScript. The entire site is navigable by keyboard and follows WCAG guidelines.

---

## Features

- **Menu across three categories**
- **Shopping basket with quantity control**
- **Live price calculation**
- **Order confirmation dialog**
- **Full keyboard navigation**
- **WCAG accessibility**
- **Responsive design**
- **Zero dependencies**
